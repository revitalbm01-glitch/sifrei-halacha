# מבנה נתוני הספרים (החוזה בין ענף התוכן לענף המסך)

ענף התוכן (`feature/content`) מייצר את הקבצים תחת `public/data/`.
ענף המסך (`feature/ui`) קורא רק אותם, ולא יודע מאיפה הגיע הטקסט.

הספר מחולק לקבצים קטנים כדי שהמסך לא יוריד ספר שלם בפתיחה:
המסך מוריד את תוכן העניינים, ואת הטקסט של נושא רק כשבוחרים בו.

## `public/data/books.json` — רשימת הספרים

```jsonc
[
  {
    "id": "yalkut-yosef",                    // שם התיקייה של הספר
    "title": "קיצור שולחן ערוך ילקוט יוסף",
    "author": "הרב יצחק יוסף",
    "source": {
      "name": "תורת אמת",
      "url": "https://toratemetfreeware.com/online/f_01355_all.html",
      "license": "CC BY-NC-SA 2.5",
      "rights": "כל הזכויות שמורות למו\"ר הרב יצחק יוסף שליט\"א"  // אופציונלי
    }
  }
]
```

## `public/data/<id>/index.json` — תוכן העניינים

```jsonc
{
  "id": "yalkut-yosef",
  "parts": [                                  // חלקים (אורח חיים...). ספר בלי חלקים: חלק אחד עם title ריק
    {
      "title": "אורח חיים",
      "topics": [
        {
          "n": 3,                             // מספר הנושא בספר (1, 2, 3... ברצף על פני כל החלקים)
          "title": "הלכות ציצית",
          "simanim": [
            { "label": "ח", "title": "מהלכות ציצית - סדר עטיפת הציצית", "seifCount": 12 }
          ]
        }
      ]
    }
  ]
}
```

## `public/data/<id>/topics/<n>.json` — הטקסט של נושא אחד

```jsonc
{
  "n": 3,
  "title": "הלכות ציצית",
  "simanim": [
    {
      "label": "ח",
      "title": "מהלכות ציצית - סדר עטיפת הציצית",
      "seifim": [
        { "label": "א", "text": "מצות עשה מן התורה... [ילקוט יוסף ספר על הלכות ציצית, סימן ח' הערה א', עמוד א']." }
      ]
    }
  ]
}
```

- `label` הוא הסימון כפי שמופיע בספר (אותיות), בלי גרשיים. סעיף בלי סימון (פתיחה וכדומה): `label` ריק.
- מראי מקומות נשארים בתוך הטקסט בסוגריים מרובעים `[...]`. המסך מציג אותם בקטן.

## `public/data/<id>/search.json` — מאגר החיפוש

נבנה מקבצי הנושאים (`npm run build-search`) וחייב להיבנות מחדש בכל שינוי בספר. הערכת הנתונים בודקת שמספר השורות שווה למספר הסעיפים.

```jsonc
{
  "id": "yalkut-yosef",
  "rows": [
    // [נושא, סימן בנושא, סעיף בסימן, סימון הסימן, סימון הסעיף, "נושא · כותרת הסימן", טקסט בלי ניקוד]
    [23, 109, 2, "שיח", "נח", "הלכות שבת · דין בישול אחר בישול", "יש אומרים דכל שרוב התבשיל..."]
  ]
}
```

## כתובות במסך

`#<id>/<n>/<siman>/<seif>` — מספר הנושא, ומספרים סידוריים של הסימן והסעיף בתוך הנושא (מ-1).
לדוגמה `#yalkut-yosef/3/1/2` = ילקוט יוסף, הלכות ציצית, הסימן הראשון בנושא, הסעיף השני.
