# DESIGN — איך האפליקציה בנויה

המסמך מתאר את התכנון הטכני והעיצובי. מה בונים ולמה: [SPEC.md](SPEC.md). מבנה הקבצים: [schema.md](schema.md).

## 1. תמונה כללית

```
 מקורות                 סקריפטי תוכן (Node)            קבצים סטטיים                 דפדפן
┌──────────────┐   ┌─────────────────────────┐   ┌───────────────────────┐   ┌──────────────────┐
│ תורת אמת     │──▶│ fetch-torat-emet.mjs    │──▶│ public/data/          │──▶│ React (src/)     │
│ (HTML)       │   │  └ torat-emet-parse.mjs │   │  books.json           │   │  data.js  טעינה  │
├──────────────┤   │ fetch-sefaria.mjs       │   │  <ספר>/index.json     │   │  App.jsx  ניווט  │
│ Sefaria API  │──▶│  └ kitzur-topics.mjs    │   │  <ספר>/topics/<n>.json│   │  Home.jsx בית    │
└──────────────┘   │ write-book.mjs          │   └───────────────────────┘   │  localStorage    │
                   └─────────────────────────┘          GitHub Pages          │   (סימניה)       │
                         רץ ידנית                                              └──────────────────┘
```

- אין שרת. הספרים נבנים פעם אחת בסקריפט, נשמרים בריפו, ומוגשים כקבצים סטטיים.
- הסקריפטים והמסך מדברים רק דרך מבנה הקבצים ב-[schema.md](schema.md). אפשר להחליף מקור בלי לגעת במסך, ולהחליף מסך בלי לגעת בתוכן.

## 2. צד התוכן

| קובץ | תפקיד |
|---|---|
| `scripts/torat-emet-parse.mjs` | פירוק HTML של תורת אמת לחלקים ← נושאים ← סימנים ← סעיפים. פונקציות טהורות, נבדקות בטסטים |
| `scripts/fetch-torat-emet.mjs` | מוריד את העמוד, מפענח windows-1255, מפעיל את הפירוק וכותב |
| `scripts/fetch-sefaria.mjs` | מוריד את קיצור שולחן ערוך מה-API של ספריא ומקבץ לנושאים |
| `scripts/kitzur-topics.mjs` | החלוקה שלנו של 221 הסימנים ל-29 נושאים |
| `scripts/write-book.mjs` | כותב ספר במבנה המפוצל ומעדכן את `books.json` |
| `scripts/eval-data.mjs` | בדיקת איכות לקבצים שנוצרו (ראו סעיף 6) |

**פירוק תורת אמת.** בעמוד יש סימון לכל רמה בהערת HTML: `<!--$#-->` חלק, `<!--$@-->` נושא, `<!--$~-->` סימן, `<!--$!-->` סעיף.
כותרות הסימנים מגיעות בכמה צורות, וכולן מזוהות: `סימן ח' - …`, `סימנים שח, שיא - …`, `סימן יד סעיף ג' - …`, `המשך סימן קו - …`.
כותרת משנה בלי מספר סימן נשמרת עם `label` ריק ומוצגת לפי שמה. גרשיים שנכתבו כשני גרשים (`רש''י`) מוחלפים ב-`"`.

**למה מפצלים לפי נושא.** ילקוט יוסף כולו שוקל כ-9MB. מסך הבית צריך רק את תוכן העניינים (עשרות KB), וכל נושא נטען כשבוחרים בו.
הנושא הגדול ביותר (הלכות שבת) שוקל 1.5MB, ובדחיסה של השרת פחות מחצי מזה.

## 3. צד המסך

| קובץ | תפקיד |
|---|---|
| `src/data.js` | טעינת JSON עם מטמון, קריאה וכתיבה של הכתובת, סימניה ב-localStorage |
| `src/hebrew.js` | הסרת ניקוד, מספרים עבריים, חיפוש שמתעלם מ-ו/י |
| `src/App.jsx` | שורה עליונה, תפריט נושאים, פירורי לחם, דפי ספר / נושא / סימן |
| `src/Home.jsx` | דף הבית: תמונה, המשך מהסימניה, ספרים, מקורות מהזוהר והתניא |
| `src/styles.css` | כל העיצוב, משתני צבע, מצב כהה, התאמה לטלפון |

**ניווט בכתובת.** כל המצב של המסך נמצא בכתובת: `#<ספר>/<נושא>/<סימן>/<סעיף>`, או `#home`.
אין router: `App` מאזין ל-`hashchange` ומציג לפי הכתובת. זה עובד ב-GitHub Pages בלי הגדרות, וכל מקום אפשר לשתף.

**טעינה.** `useJson(path)` טוען כל קובץ פעם אחת ושומר במטמון. בזמן מעבר בין נושאים מוצג "טוען…" ולא הטקסט הקודם.

**סימניה.** אובייקט אחד ב-localStorage (`sifrei-halacha:bookmark`). אם הדפדפן חוסם אחסון, האפליקציה ממשיכה לעבוד בלי סימניה.
כניסה בכתובת ריקה מחליפה את הכתובת (בלי רשומה בהיסטוריה) לכתובת הסימניה.

## 4. עיצוב

- **צבעים** — משתנים ב-`:root` (`--bg`, `--surface`, `--text`, `--muted`, `--border`, `--accent`, `--accent-soft`, `--highlight`), עם ערכים למצב כהה תחת `prefers-color-scheme: dark`. גוון חם של קלף ועץ, הדגשה בחום-זהב.
- **גופנים** — Frank Ruhl Libre (סריף עברי קלאסי) לטקסט ההלכה ולכותרות, Heebo לממשק ולמראי מקומות.
- **היררכיה בסעיף** — אות הסעיף בצבע ההדגשה, טקסט ההלכה בגודל 1.2rem ובמרווח שורות 1.9, מראי מקומות בקטן ובצבע מעומעם.
- **פריסה** — במחשב: שורה עליונה, תפריט נושאים קבוע בצד ימין, טקסט ברוחב קריאה של עד 54rem. בטלפון (עד 760px): התפריט נפתח בכפתור "נושאים" ומכסה את המסך.
- **נגישות** — `lang="he" dir="rtl"`, כפתורי סימניה עם `aria-pressed`, ניווט עם `aria-label`, תמונה עם טקסט חלופי.

## 5. החלטות ושיקולים

| טקסט שמור בריפו | האתר לא תלוי במקורות בזמן ריצה | צריך להריץ סקריפט כדי לעדכן |
| פיצול לפי נושא | פתיחה מהירה בטלפון | חיפוש בכל הטקסט דורש להוריד הכול |

## 6. חיפוש בשאלה חופשית

```
שאלה ──▶ מילים (בלי מילות שאלה) ──▶ מילון מושגים ──▶ מונחים + משקלים ──▶ BM25 על כל הסעיפים ──▶ 20 תוצאות
"אפשר לחמם    לחמם, שניצל, בשבת       "חימום אוכל        + בישול אחר בישול,   ציון לפי שכיחות,       ספר · נושא ·
 שניצל בשבת?"                          בשבת", "שבת"        תבשיל יבש, רוטב...   כותרת, ונושא מתאים     סימן · סעיף
```

| קובץ | תפקיד |
|---|---|
| `src/search.js` | מנוע החיפוש. פונקציות טהורות, אותו קוד בדפדפן ובהערכה |
| `src/concepts.json` | מילון מושגים: מילים יומיומיות ← מונחי הספר, ונושא לחיזוק |
| `src/SearchPage.jsx` | מסך החיפוש: טעינת המאגר בפעם הראשונה, סינון לפי ספר, הדגשת מילים |
| `scripts/build-search-index.mjs` | בונה `search.json` לכל ספר |
| `scripts/eval-search.mjs` | הערכה על שאלות בשפה טבעית |

**התאמת מילים.** כל מילה מנורמלת: בלי ניקוד, אותיות סופיות רגילות, בלי ו/י פנימיות (כתיב מלא = חסר), ובשלוש גרסאות עם הורדת אותיות שימוש (ו ה ב ל מ ש כ), כל עוד נשארות 3 אותיות לפחות. מילה שמסתיימת ב-ת מקבלת גם גרסה ב-ה (סמיכות).

**דירוג.** BM25 על טקסט הסעיף, עם תוספת למילה שמופיעה בכותרת הנושא או הסימן. מונחים מהמילון שוקלים פחות ממילות השאלה עצמה. סעיף שמכיל יותר ממילות השאלה מקבל תוספת, וכך גם סעיף בנושא שהמילון זיהה (למשל "שבת").

**מגבלות ידועות.** אין הבנת משמעות מעבר למילון: שאלה שמנוסחת במילים שאינן בספר ואינן במילון לא תמצא את המקור. השלב הבא הוא שכבת הבנה עם Claude (Issue #3 ואילך), שתשתמש במנוע הזה כחלק מהחיפוש.

## 7. בדיקות

- **טסטים** (`npm test`, Vitest): פונקציות העברית, ניווט וסימניה, ופירוק כותרות של תורת אמת. בתיקייה `tests/`.
- **הערכת נתונים** (`npm run eval`): בודקת את הקבצים שנוצרו מול הסכמה, מול ציפיות מספריות לכל ספר, ומול דגימות טקסט ידועות. מפרטת כל כשל.
- **הערכת חיפוש** (`npm run eval:search`, רצה גם בתוך `npm run eval`): 21 שאלות כיוונון ו-6 שאלות בדיקה בשפה טבעית, עם מקורות שאותרו בקריאת הספרים ולא על ידי המנוע. מודדת באיזה מקום מופיע המקור הנכון, ומשווה לחיפוש הכותרות הקודם ולחיפוש בלי מילון.
- שניהם רצים ב-GitHub Actions לפני כל פרסום. כשל עוצר את הפרסום.
