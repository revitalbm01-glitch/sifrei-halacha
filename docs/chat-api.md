# ממשק הצ'אט (החוזה בין `feature/chat-server` ל-`feature/chat-ui`)

השרת (`server/`) רץ על פורט 8787. בפיתוח, Vite מעביר אליו כל בקשה ל-`/api`.

## `POST /api/chat`

גוף הבקשה (JSON) — כל השיחה עד עכשיו, האחרונה היא השאלה החדשה:

```json
{ "messages": [
  { "role": "user", "content": "מה מברכים על בננה?" },
  { "role": "assistant", "content": "..." },
  { "role": "user", "content": "ואם היא מבושלת?" }
] }
```

התשובה היא NDJSON (שורת JSON אחת לכל אירוע), בזרימה:

```jsonc
{ "type": "sources", "simanim": [ { "number": 52, "title": "דיני ברכת הפירות" } ] } // הסימנים שנשלפו
{ "type": "text", "text": "על פרי האדמה מברכים..." }                                    // חלק מהתשובה, כמה פעמים
{ "type": "done" }
{ "type": "error", "message": "..." }                                                   // במקום done, אם נכשל
```

## ציון מקורות בתוך התשובה

התשובה מצטטת במבנה קבוע עם מספרים רגילים: `[סימן 52 סעיף 3]`.
המסך הופך כל ציון כזה לקישור `#52:3` שפותח את הסעיף בתצוגת הספר.
