# SPEC — ספרי הלכה לפי נושא, סימן וסעיף

## 1. מטרה
אפליקציית רשת חינמית לקריאה בספרי הלכה, שבה המשתמש בוחר ספר ← נושא ← סימן ← סעיף ומגיע מהר להלכה שהוא מחפש.
המטרה ארוכת הטווח: צ'אט שעונה על שאלות בהלכה מתוך ילקוט יוסף, עם הפניה לסימן ולסעיף (ראו סעיף 9).

## 2. משתמשים
- לומדים ושואלים שרוצים לקרוא הלכה מסודרת לפי נושא, בעיקר לפי פסקי מרן ומנהג ספרד.
- רוב השימוש צפוי מהטלפון, ולכן המסך מותאם קודם כול לטלפון.

## 3. עקרונות
1. **חינם לגמרי** — בלי שרת, בלי מסד נתונים ובלי שירות בתשלום. האתר הוא קבצים סטטיים בלבד.
2. **נאמנות למקור** — הטקסט מוצג כפי שהוא במקור, עם מראי המקומות, וכל עמוד מציין את המקור, את בעל הזכויות ואת הרישיון.
3. **קל ומהיר** — הספר מחולק לקבצים לפי נושא, והמסך מוריד רק את מה שצריך.
4. **עברית מימין לשמאל** בכל המסכים.

## 5. דרישות
### 5.1 ניווט
- בחירת ספר מהשורה העליונה. ברירת המחדל: ילקוט יוסף.
- **דף ספר:** כל הנושאים ככרטיסים, מקובצים לפי חלקים (אורח חיים, יורה דעה, חושן משפט, אבן העזר).
- **דף נושא:** רשימת הסימנים עם מספר הסימן, הכותרת ומספר הסעיפים.
- **דף סימן:** כותרת, שורת קפיצה לכל סעיף, כל הסעיפים, ומעבר לסימן הקודם/הבא (גם מעבר לנושא הבא/הקודם).
- פירורי לחם: ספר ‹ נושא ‹ סימן.
- תפריט צד עם כל הנושאים. בטלפון הוא נפתח בכפתור "נושאים".

### 5.2 כתובות
לכל מקום בספר יש כתובת שאפשר לשתף: `#<ספר>/<נושא>/<סימן>/<סעיף>` (מספרים סידוריים מ-1).
פתיחת כתובת של סעיף גוללת אליו ומדגישה אותו.
כתובות נוספות: `#home` (דף הבית), `#search` (דף החיפוש), `#search/<שאלה>` (תוצאות לשאלה, אפשר לשתף).

### 5.3 חיפוש
- **בתפריט הנושאים:** חיפוש מהיר בשמות נושאים וסימנים בספר הנוכחי.
- **שאלה חופשית** (`#search/<שאלה>`, מדף הבית או מאייקון החיפוש): חיפוש בטקסט של כל הסעיפים בשני הספרים, בעברית יומיומית ("אפשר לחמם שניצל בשבת?").
  - מתעלם מניקוד, מ-ו/י, מאותיות שימוש (ו ה ב ל מ ש כ) ומסמיכות (תפילת = תפילה).
  - מילון מושגים ([src/concepts.json](../src/concepts.json)) מרחיב את השאלה למונחי הספר ("לחמם" + "שבת" ← בישול אחר בישול, תבשיל יבש, רוטב…). המילון רק מוסיף מילות חיפוש ואינו קובע הלכה.
  - מוצגים 20 סעיפים, עם מיקום מלא (ספר · נושא · סימן · סעיף), קטע מהטקסט עם המילים שנמצאו, וסינון לפי ספר.
  - מאגר החיפוש (כ-2.5MB בדחיסה) נטען רק בחיפוש הראשון.
  - הודעה קבועה: אלה תוצאות חיפוש ולא פסק הלכה.
  - **"על מה אפשר לשאול"**: רשימת נושאים שבהם החיפוש מבין ניסוח יומיומי, עם שאלות לדוגמה ([src/search-subjects.json](../src/search-subjects.json)). מופיעה בדף החיפוש, עם קישור מדף הבית. כל דוגמה היא שאלה שנבדקת בהערכה, וחייבת להביא מקור נכון ב-3 התוצאות הראשונות. דוגמה שלא עומדת בזה יורדת מהרשימה.
- **איכות:** נמדדת על שאלות בשפה טבעית עם מקורות ידועים (`npm run eval:search`), ונבדקת לפני כל פרסום.

### 5.4 תצוגה

- מראי מקומות בסוגריים מרובעים מוצגים בקטן ובצבע מעומעם.
- מצב כהה לפי הגדרות המכשיר.
- בלי גלילה אופקית ברוחב טלפון (375px).

### 5.5 דף הבית
- כתובת `#home` (וגם הכתובת הריקה כשאין סימניה). לחיצה על "ספרי הלכה" בשורה העליונה חוזרת אליו.
- תמונה של בחורים לומדים, כותרת, ותיבת "שאלו שאלה" שפותחת את החיפוש, עם קישור "על מה אפשר לשאול?".
- כפתור "המשך מהסימניה" (אם יש), וכרטיס לכל ספר.
- "חשיבות לימוד ההלכה": ציטוטים מהזוהר (אחרי מות, ח"ג עג ע"א) ומהתניא (ליקוטי אמרים פרקים ה, כג), כלשונם במקור.
- בטלפון התמונה מעל הכותרת, במחשב לצידה.

### 5.6 סימניה
- ליד כל סעיף כפתור סימניה. לחיצה שומרת את המקום, לחיצה נוספת מוחקת. יש סימניה אחת.
- הסימניה נשמרת בדפדפן של המכשיר (localStorage), בלי חשבון ובלי שרת.
- כניסה לאתר בכתובת הריקה פותחת ישר את הסעיף המסומן. בשורה העליונה יש קיצור דרך לסימניה.

### 5.7 קרדיט
בתחתית כל עמוד: הערת הזכויות של הספר (אם יש), קישור למקור, והרישיון.

## 6. ארכיטקטורה
- **מסך:** React 18 + Vite, אתר סטטי ([src/](../src)).
- **תוכן:** סקריפטים ב-Node שמורידים את הספרים מהמקור ושומרים אותם כ-JSON תחת `public/data/` ([scripts/](../scripts)). הקבצים נשמרים בפרויקט, כך שהאתר לא תלוי במקורות בזמן ריצה.
- **מבנה הנתונים:** מתואר ב-[schema.md](schema.md): `books.json` (רשימת ספרים), `<ספר>/index.json` (תוכן עניינים), `<ספר>/topics/<n>.json` (טקסט של נושא), `<ספר>/search.json` (מאגר החיפוש).
- **חיפוש:** מנוע ב-[src/search.js](../src/search.js) שרץ בדפדפן, מילון מושגים ב-[src/concepts.json](../src/concepts.json). פירוט ב-[DESIGN.md](DESIGN.md).
- **פרסום:** GitHub Pages, נבנה ומתפרסם אוטומטית בכל דחיפה ל-`main` ([.github/workflows/deploy.yml](../.github/workflows/deploy.yml)), רק אם הבדיקות עוברות (סעיף 8).

## 7. ענפים וניהול משימות
- `main` הוא מה שמפורסם באתר. כל הענפים מוזגו אליו.
- עבודה חדשה נעשית בענף משלה, לפי המשימה (למשל `issue-10-smart-search`), ונכנסת ל-`main` עם `Closes #<מספר>`.
- שינוי במבנה הנתונים נעשה קודם ב-[schema.md](schema.md).
- המשימות מנוהלות ב-GitHub Issues ובלוח העבודה ([תוכנית עבודה](https://github.com/users/revitalbm01-glitch/projects/1)). פירוט ב-[MANAGEMENT.md](MANAGEMENT.md) וב-[PLAN.md](PLAN.md).

## 8. בדיקות ואיכות
כל דחיפה ל-`main` מריצה את כולן, והאתר מתעדכן רק אם כולן עוברות.
- **טסטים** (`npm test`): עברית, ניווט, סימניה, פירוק תורת אמת, נושאי קיצור שו"ע, מנוע החיפוש ודוגמאות החיפוש.
- **הערכת נתונים** (`npm run eval`): מבנה הספרים, ניקיון הטקסט, מספר נושאים, סימנים וסעיפים, דגימות טקסט ידועות, והתאמת מאגר החיפוש לספר.
- **הערכת חיפוש** (`npm run eval:search`): שאלות בשפה טבעית עם מקורות שאותרו בקריאת הספרים.
  - שאלות הכיוונון: מקור נכון ב-5 הראשונים בלפחות 80% (היום 90%).
  - שאלות בדיקה שלא כוונן עליהן: לפחות 50% (היום 100%).
  - כל דוגמה שמוצגת במסך: מקור נכון ב-3 הראשונים.
